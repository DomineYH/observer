# PROTOTYPE — 교신 문장을 말했을 때 후보 인식기가 듣는 글 (#177)

버려도 되는 페이지다. 제품 코드가 아니고 main에 합치지 않는다.

**질문:** 소유자가 교신 문장을 직접 말했을 때 후보 인식기는 무엇을 듣는가. 어느 인식기가 쓸 만한가를 문서가 아니라 잰 값으로 답한다.

## 돌리는 법

WSL에서(의존성이 리눅스용으로 설치돼 있다):

```sh
cd /mnt/c/dev/observer-m4-voice
npm run proto:voice
```

그다음 **Windows Chrome**(기준 데스크톱)에서 <http://localhost:5177/prototype-voice.html>을 연다. 시크릿 창은 쓰지 않는다(vosk가 모델을 저장하다 멈춘다).

1. "모델 미리 받기"를 누른다. Whisper는 처음 한 번 Hugging Face에서 받는다(tiny 39 MiB, base 73 MiB).
2. "내장·기기 안 한국어 설치"를 누른다(Chrome 139+). 안 되면 그 칸은 오류 글로 남는다.
3. 화면의 문장을 스페이스(또는 단추)를 누른 채 읽고 뗀다. 인식기마다 들은 글과 걸린 시간이 표에 선다. →로 다음 문장. 문장은 25개다.
4. "결과 내려받기"로 JSON을 받는다. "녹음 포함"을 켜 두면 같은 소리로 다른 인식기를 나중에 다시 잴 수 있다. 목소리가 든 파일이라 저장소에 올리지 않는다(`.gitignore`에 있다).

Whisper를 돌리는 곳을 `webgpu`로 바꿔 한 번 더 재면 속도 차이를 볼 수 있다.

## 페이지가 하는 일

- 문장은 게임의 문장 만들기(`radioSentence`)가 교신 문법에서 만든다(`sentences.ts`). 문형마다 하나 이상이고 한 자리씩 읽는 수, 백·십 단위, 발수, 음성 문자, 복창이 들어 있다.
- 말하는 동안 16 kHz로 녹음하고, 내장·클라우드 인식은 같은 마이크를 실시간으로 듣는다. 떼면 녹음 하나를 나머지 인식기에 차례로 넣는다(시간이 서로 섞이지 않게 하나씩).
- 내장·기기 안 모드는 녹음을 다시 틀어서 듣게 한다(`start(track)`). 이 호출은 헤드리스 Chrome에서 확인하지 못했다.
- 초록 칸은 띄어쓰기와 문장부호를 뺀 글이 말한 문장과 같은 칸이다.

## 지금까지 잰 것 (2026-11-23, 이 PC의 WSL 헤드리스 Chrome 156, 교신 문장이 아닌 공개 표본 소리 둘, 각 3.5초)

| 인식기 | 들은 글 | 걸린 시간 |
| --- | --- | --- |
| vosk small-ko | "그 는 괜찮은 착해 계약을 했으며 각 했다" / "지하철 에서 다리를 벌리고 했지" | 6.5–7.0초 |
| vosk small-ko + 구절 문법 | 문법의 낱말만 나온다(표본이 교신 문장이 아니라 뜻 없는 글) | 1.5초 |
| Whisper tiny (wasm 한 스레드) | "그릇 괜찮은 척하려고 S는 것 같았다" / "지하철에서 다리를 벌리고 한지 말아" | 5.2–8.6초 |
| Whisper base (wasm 한 스레드) | "그는 괜찮은 척하려고 S는 것 같았다." / "지하철에서 다리를 벌리고 앉지 마라." | 10.0–12.4초 |

- vosk small-ko에는 `Gr.fst`가 있어 구절 문법이 된다. 그러나 **모델 어휘에 없는 교신 낱말이 23개**다: 효력사, 재효력사, 임무끝, 좌로, 우로, 표적번호, 사격지휘통보, 순발신관, 접근신관, 위험근접, 지명사, 잠깐대기, 마감탄, 전이, 여기는, 보병소대, 공격중인, 이동중인, 사격중인, 동제원, 1개, 2대, 3문. 없는 낱말은 문법에서 빠진다.
- vosk-browser는 표본을 −1…1 그대로 받는다. 16비트 범위로 키우면 엉뚱한 글이 나온다.
- vosk 모델을 올리는 데 3–8초, Whisper 모델을 받는 데 15초쯤 걸렸다.
- 내장 인식 둘은 헤드리스 Chrome에서 `audio-capture`와 `language-not-supported` 오류였다. 실제 Chrome에서만 잴 수 있다.

## 넣지 못한 것

- **sherpa-onnx 한국어 Zipformer:** 미리 빌드된 한국어 WASM을 찾지 못했다. Emscripten으로 직접 빌드해야 한다. 내려받은 녹음으로 나중에 따로 잴 수 있다.
- SenseVoice, Moonshine 한국어: 가중치 약관이 따로 있어 뒤로 미뤘다.
