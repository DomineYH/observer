# 지형의 정체는 식별자와 판이고 해시 밖에 두며, 정사각 밖은 거울 규칙을 유지한다

실제 지형(M2)이 들어와도 시뮬레이션의 지형 질의는 바꾸지 않는다. 지형 자료에 전장 식별자(`id`)와 지형 판(`version`)을 더하되 지형 해시에는 넣지 않는다. 해시는 지금 넣는 바이트열을 얼리고, 새 내용 필드(도로 등급, 지명, 정사각 밖 그리기 방식, 숲 규칙의 층)는 꼬리표 달린 덩이로 뒤에 붙이며 mock의 기본값이면 생략한다. 그래서 계약이 넓어져도 mock의 해시와 골든 기록, `simVersion`이 그대로다. 식별자·판과 해시의 짝은 실제 지형 수용 테스트가 지킨다.

정사각 밖 좌표는 지금처럼 거울 지형으로 읽는다. 가시선은 정사각 안 두 점 사이라 밖을 읽지 않고 포대는 지형을 읽지 않으므로, 거울이 결과에 닿는 곳은 바깥쪽 레이저와 정사각 밖 탄착의 높이뿐이다. 실제 지형에서 거울 땅은 실제와 다르므로(문경 가장자리 밖 RMS 164 m) 관측 화면에서만 안개 띠로 가린다. 그리는 방식은 지형 자료의 값(`edge`)이 말하고 mock은 데모 그대로 거울을 그린다.

## Considered Options

- **식별자·판을 해시에 넣기**: 정체가 한 값으로 묶이지만 mock 해시가 바뀌어 `simVersion`을 올리고 모든 골든을 다시 만들어야 한다.
- **가장자리 띠(정사각 밖 실제 지형을 거친 층으로 싣기)**: 그림과 레이저가 실제 땅과 맞는다. 그러나 전장 확인을 하지 않은 땅을 싣게 되고 층·해시·그리기 색이 하나씩 더 든다. 사람 검수에서 안개 띠가 어색하면 선택 필드로 더한다.
- **가장자리 값 늘리기(clamp)**: 가장자리가 줄무늬 평면이 되고 mock 결과가 바뀐다.

## Consequences

- 실제 가공 자료가 바뀌면 지형 판만 오르고 `simVersion`은 그대로다. 시뮬레이션의 지형 질의나 mock 생성기가 바뀌면 `simVersion`이 오른다.
- 새 내용 필드는 선택 필드이고, 없을 때의 결과가 지금과 비트까지 같아야 한다.
- 표면 높이(`surface`)는 지형 파일에 없고 풀기 함수가 지면·피복·건물 높이에서 만든다. 그래서 만드는 식을 고치면 파일이 같아도 해시가 달라지고 지형 판이 오른다.
- 가공 자료 머리는 자기가 나온 원자료 스냅샷의 체크섬을 싣는다.
- 벌채지에는 선택 필드도 해시 꼬리 덩이도 필요 없다. 벌채 원 목록은 가공 자료 머리에 있고, 지형 자료에는 이미 바뀐 피복과 표면만 들어간다.
- 바깥쪽을 겨눈 레이저는 안개 뒤 거울 지형까지 거리를 잰다.
