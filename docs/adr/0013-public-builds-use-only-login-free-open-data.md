# 공개 빌드는 로그인 없이 받는 공개 라이선스 자료만 쓴다

실제 지형의 층마다 자료원이 여럿 있었다. 지면은 GEDTM30 v1.2(사용자 결정), 피복 바탕은 ESA WorldCover 10 m 2021 v200(CC BY 4.0), 건물·도로·지명·강·저수지는 OpenStreetMap(ODbL 1.0)을 쓴다. 숲 높이는 임상도가 아니라 데모 상수 12–17 m다(ADR 0011). 환경부 세분류 토지피복, 산림청 임상도, 국토부 건물통합정보는 로컬 가공에도 쓰지 않는다. 로컬과 공개 빌드의 그림이 다르면 검수가 무의미하고, CI가 키 없이 같은 자료를 다시 만들 수 있어야 하기 때문이다. 세 국내 자료의 공공측량성과 해당 여부와 해외 호스팅 조건도 확인되지 않았다.

## Considered Options

- **국내 고해상 자료(세분류 41종, 임상도, 건물통합정보)**: 피복과 숲 높이가 더 정확하지만 로그인·키가 필요하고 공개 배포 조건이 미확인이다.
- **로컬만 국내 자료, 공개는 공개 자료**: 두 빌드의 그림이 갈라져 사람 검수가 공개 빌드를 대신 보지 못한다.
- **Overture Maps로 건물 보강**: 한국 농촌의 채움 비율을 재 본 적이 없어 지금은 고르지 않았다.

## Consequences

- 받기는 계정·키·손 내려받기 없이 돈다(ADR 0010). 원천마다 주소·판·라이선스·자료 출처 문구를 가공 설정에 적고, 작전 준비 화면 맨 아래에 자료 출처 줄을 보인다.
- WorldCover는 7종 피복으로 옮기고 표에 없는 값이면 가공이 멈춘다. 덮어쓰기 순서는 OSM 건물 > OSM 도로 > OSM 수면 > WorldCover다.
- OSM 추출본이 저장소와 지형 파일에 들어가므로 공개 전에 ODbL 조건(출처 표기, 데이터베이스 공유)을 확인한다.
- 제공기관의 답이 오면 국내 자료를 다시 연다. 그때는 가공 규칙 판과 지형 판이 오른다.
