# 포는 시나리오의 속성이 아니라 판을 만드는 값이고 일일 판은 기본 포로 한다

PRD 7.2는 포 프로파일을 "시나리오 속성으로 선택"한다고 적었지만, 포는 시나리오와 나란히 판을 만들 때 주는 값으로 두고 시나리오는 포를 가리키지 않게 했다. 일일 시드 판은 모드가 무엇이든 늘 기본 포(데모의 155mm 견인포 6문, `base`)이고, 다른 포는 연습의 작전 준비에서만 고른다. `base`는 KH178·KH179·K55·K9와 별개인 다섯째 프로파일로 남긴다.

시나리오가 포를 가리키면 같은 땅·같은 적에 포만 바꿔 보려 해도 시나리오를 하나 더 써야 하고, 기본 시나리오에 값이 더해져 버전과 골든에 닿는다. 일일 판에서 포를 고르게 하면, 시제품(#118)에서 K9가 모든 사거리에서 24–38초 빠르고 그것을 깎는 규칙이 없으므로 보드가 "K9를 골랐는가"가 된다. 시드가 고르게 하면 105mm를 뽑은 날이 다른 날보다 어려워 전체 기간 보드가 날짜 운에 좌우된다. `base`를 KH179라 부르지 않은 것은 `base`의 효력사 간격 9초가 공개된 KH179의 15초와 다른 게임 값이기 때문이다.

시나리오가 포에 거는 제약은 포대 자리뿐이므로 판을 만들기 전에 사거리를 검사한다: 포대에서 싸움터의 가장 먼 점(접근로, NAI 원, 박격포 상자, 아군 진지)까지 + 500 m가 포의 최대 사거리 안이어야 한다. 지도 정사각 전체를 요구하면 105mm(14.7 km)는 기본 시나리오(먼 모서리 16.0 km)에서 쓸 수 없게 된다. 모든 시나리오는 기본 포로 이 검사를 통과해야 한다. 판 도중의 "사격 불가"는 없다.

포 사이에 맞바꿈을 만드는 규칙(진지 변환, 적 대포병)이 생기면 "일일 판은 늘 기본 포"는 다시 볼 수 있다.
