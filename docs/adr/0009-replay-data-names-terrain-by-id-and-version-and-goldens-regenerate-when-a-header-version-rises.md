# 재생 자료는 지형을 식별자와 판으로 가리키고, 골든 기록은 없을 때 만들고 머리의 버전이 오를 때만 다시 만든다

실제 지형(M2)은 시드로 다시 만들 수 없다. 재생 자료 머리에 선택 필드 `terrain`(전장 식별자와 지형 판)을 더하고, 없으면 시드로 만든 mock 지형을 뜻한다. mock은 늘 생략하므로 `format`은 1이고 mock 골든 기록은 바뀌지 않는다. 지형 해시는 재생 자료에 싣지 않는다. 제출자가 적은 해시는 검증에 쓸 수 없기 때문이다. 해시는 가공 자료 머리에 적혀 오고, 지형 원천이 자료를 푼 뒤 다시 계산해 빌드에 실린 기대값과 견주며, 다르면 판을 시작하지 않는다. 재생기는 넘겨받은 지형의 식별자·판이 머리와 다르면 재생하지 않는다. 시나리오와 포 프로파일의 식별자·버전, 실전 판의 실전 자료 판도 같다.

실제 지형 자료가 바뀌면 지형 판만 오르고 `simVersion`은 그대로다. 그래서 ADR 0005의 "골든은 `simVersion`이 오를 때만 다시 만든다"를 넓힌다. 골든 파일이 없으면 새로 만든다(실제 지형 골든 ⑤처럼). 파일이 있으면 골든 머리의 다섯 버전(`simVersion`, 지형 판, 시나리오 버전, 포 프로파일 버전, 실전 판의 골든에는 실전 자료 판) 가운데 코드·자료 쪽이 더 큰 것이 있고 더 작은 것이 없을 때만 다시 만들고, 지형·시나리오·포 프로파일의 식별자가 다르면 다시 만들지 않는다. 실제 지형 골든 기록의 머리(식별자·판과 지형 해시)가 "같은 판이면 같은 해시"를 잠근다.

## Considered Options

- **`format`을 2로 올리고 지형을 필수 필드로**: 표기가 하나로 고르지만 mock 골든 파일을 다시 써야 하고, 그 길은 `simVersion`을 올리는 것뿐이다.
- **재생 자료에 지형 해시를 싣기**: 한 값으로 내용까지 가리키지만 크기 비교가 안 되어 다시 만들기 조건에 쓸 수 없고, 제출된 값이라 서버가 믿을 수 없다.
- **자료가 바뀔 때도 `simVersion`을 올리기**: 규칙이 하나로 남지만 벌채지 하나를 고쳐도 mock 골든과 모든 옛 기록이 무효가 된다.
- **적힌 해시만 믿고 받을 때 계산하지 않기**: 쪽을 여는 시간이 줄지만(데스크톱 약 0.25초) 엔진마다 자료를 푼 결과가 같은지, 옛 캐시 자료가 섞였는지 알 수 없다.

## Consequences

- 실제 지형의 해시 값이 달라지는 변경은 바이트가 같아도 지형 판을 올린다.
- 옛 지형 판의 기록은 다른 `simVersion`의 기록처럼 재생하지 않는다. 옛 판 자료의 보관은 서버 재생 검증(M6)이 정한다.
- 자료를 푸는 함수는 받기와 떼어 DOM 없이 두어 Node 테스트와 서버가 같은 함수를 쓴다.
- 포 프로파일의 값이 바뀌면 그 프로파일의 버전이 오르고 `simVersion`은 그대로다. 프로파일을 읽는 식이 바뀌면 `simVersion`이 오른다. M3에서 포 수치가 코드에서 자료로 나왔기 때문이다(ADR 0014).
- mock 골든에도 시나리오 버전을 올려 다시 만드는 길이 생긴다.
- 버전은 다섯이고 바뀌는 것마다 하나가 받는다: 시뮬레이션 코드가 내는 결과는 `simVersion`, 실제 지형의 가공 자료는 지형 판, 시나리오의 값(증원 밖)은 시나리오 버전, 포 프로파일의 값(진지 변환 시간 밖)은 포 프로파일 버전, 실전에서만 읽는 값은 실전 자료 판. 시뮬레이션이 읽지 않는 값(예비 관측소, 최대 사거리)도 그 자료의 버전에 든다.
- 버전이 오르지 않는 것: 글과 일일 시작일, 값이 같은 모양 바꾸기, 아무도 읽지 않던 칸을 처음 채우기, 없을 때의 동작과 같은 값으로 채운 새 필드, 새 시나리오나 새 포 프로파일을 더하기.
- 저장소에는 식별자마다 지금 버전의 자료만 둔다. 내용과 버전의 짝은 테스트 곁의 기대값 표(조각마다 한 줄, 값을 열쇠를 정렬한 JSON으로 적은 글의 SHA-256)가 지키고 앱은 실행 때 견주지 않는다. 옛 버전 자료의 보관은 서버 재생 검증(M6)이 정한다.
- 재생기에 넘길 자료는 재생 자료 머리의 식별자로 찾는다. 찾는 자리는 하나이고 테스트, 실행 환경 검사, 서버가 같이 쓴다. 모르는 식별자나 다른 버전은 거부한다.
- M3는 골든 기록 7개를 고치지 않았고 `simVersion`은 17로 남았다. 그 7개는 기대값을 적은 테스트가 따로 잠근다.
