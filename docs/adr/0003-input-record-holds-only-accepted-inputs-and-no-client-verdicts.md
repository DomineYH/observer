# 입력 기록은 받아들인 입력만 담고, 클라이언트의 판정 결과는 싣지 않는다

데모 v0.2와 PRD 7.5는 상태 가드에 걸린 입력을 재생에서도 "무시"하고, 식별 입력에 클라이언트가 판정한 표적 번호(pid)를 싣고, 일시정지를 입력으로 기록한다. M1은 셋 다 바꾼다. 시뮬레이션은 입력마다 받아들였는지를 알려 주고 입력 기록에는 받아들인 입력만 남기며, 재생 검증은 재생 중 하나라도 무시되는 입력이 나오면 그 기록을 무효로 본다. 식별 입력은 누른 지점의 각도(0.1밀 정수)만 싣고 어느 표적인지는 시뮬레이션이 판정한다. 일시정지·배속은 시뮬레이션 상태가 아니므로 기록하지 않는다. 입력 기록의 종류와 값 형식은 M1부터 버전 번호(`format`)가 붙은 계약이고 값은 정수·열거형뿐이다.

## Considered Options

- **재생에서도 무시(PRD 7.5)**: 구현은 같지만, 조작된 기록이 "우연히 통과하는 입력 열"을 찾는 여지를 남기고, 정직한 기록과 깨진 기록을 구분하지 못한다. 받아들인 입력만 기록하면 엄격한 거부가 공짜로 따라온다.
- **식별에 pid만 / pid와 각도 둘 다**: pid만 실으면 서버가 클라이언트 판정을 믿게 되고 판정이 렌더러 해상도에 묶인다(데모). 둘 다 실으면 둘이 어긋날 때의 규칙이 하나 더 필요하다.
- **형식 고정을 M6 직전으로 미룸**: 골든 기록과 결정성 관문이 M1부터 이 형식에 기대므로 미뤄도 사실상 고정된다.

## Consequences

- FDC가 규칙으로 거절하는 입력(위험근접 100 m 초과 수정 등)은 "받아들인 입력"이다. 상태를 바꾸므로 기록에 남는다. 무시는 상태 가드에 걸려 아무 일도 일으키지 않은 입력만 가리킨다.
- 조준 방향은 입력으로만 시뮬레이션에 들어가므로, 화면의 조준과 시뮬레이션의 조준은 최대 1밀까지 다를 수 있다(조준 입력은 1밀 이상 변할 때만 보낸다).
- 결과가 달라지는 변경마다 `simVersion`을 올려야 하고, 버전이 다른 옛 기록은 M1에서 재생하지 않는다.
