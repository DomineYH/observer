# 실전의 복창은 기록되는 입력이고 시뮬레이션이 판정하며, 밀린 복창은 시계가 아니라 다음 송신을 막는다

PRD §8과 11.2는 실전 모드에서 "기러기 교신을 플레이어가 복창해야 진행"한다고만 적었다. M3는 복창을 입력 종류 하나(`readback`)로 둔다. 값은 플레이어가 넣은 것(무엇을 복창하는가와 슬롯 값)뿐이고 맞았는지는 시뮬레이션이 판정한다. 틀린 복창은 받아들인 입력이다: 넣은 대로 무전에 나가고, 노출에 세어지고, 기러기의 정정을 부른다(ADR 0003의 "규칙으로 거절하는 입력"). 복창이 밀려 있는 동안에는 그 임무의 다음 송신이 받아들여지지 않는다. 기러기는 복창을 기다리지 않고 탄도 복창과 상관없이 나간다. 기한을 재는 시계와 감점은 없다.

## Considered Options

- **화면에서만 다루기(시제품)**: 시뮬레이션을 건드리지 않지만 복창이 노출에 들어가지 않고, 재생 검증이 "복창해야 진행"을 확인하지 못하며, 실전 골든이 복창을 단언할 수 없다.
- **감점**: 새 점수 항목과 판 기록 항목이 생겨 골든 기록의 판 기록이 바뀌고 랭킹 규칙까지 번진다.
- **시계로 재는 기한(게임 시간)**: ×8에서 실제 시간 몇 초가 되어 사람이 지킬 수 없다. 실제 시간으로 재면 시뮬레이션이 벽시계를 알아야 한다.
- **복창을 기다렸다 쏘기**: 통제 방법이 없는 사격은 준비되는 대로 쏜다는 공개 교범과 어긋나고, 모든 모드에 같은 기러기의 응답 시간을 실전에서 바꾼다.
- **끝말 "끝"(OUT)을 더하기**: 미군 교범의 끝말이지만 한국어 근거가 없고, 예문의 복창 끝맺음 "잠깐대기"와 한 판 안에서 갈린다.

## Consequences

- 훈련·표준 판은 `readback`을 받아들이지 않고 관측자의 복창이 지금처럼 저절로 나간다. 실전이 더하는 상태(밀린 복창)는 실전에서만 상태 해시에 든다.
- 복창하지 않는 쪽이 이득이 되지 않는다: 복창은 노출 1점(`설계`)을 쓰지만 하지 않으면 임무가 나아가지 않는다.
- 틀린 복창에는 횟수 한도가 없다. 대가는 시간과 노출이다.
- 음성 입력(M4)은 알아들은 말을 같은 입력으로 바꿔 넣는다. 시뮬레이션과 재생 자료는 바뀌지 않는다.
- 조정할 수는 정정 지연 하나이고 실전 수치에 둔다. 복창할 교신을 보이는 시간은 화면의 수다.
