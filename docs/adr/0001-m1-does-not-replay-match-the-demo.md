# M1은 데모 v0.2와 재생 결과 일치를 요구하지 않는다

데모 v0.2는 M1의 동작 기준이지만, M1의 통과 관문에서 "데모와 같은 시드·입력에서 같은 결과"는 뺐다. 브라우저와 서버 사이 결정성을 얻으려면 시뮬레이션의 초월 함수와 가우시안 난수 방식을 결정적 구현으로 바꿔야 하고, 그 순간 같은 시드에서도 탄착이 데모와 달라져 최종 점수 수준의 일치도 보장할 수 없기 때문이다. 대신 결정성 관문은 M1 자신에 대해 건다: 같은 시드와 입력 기록이 Chromium·Firefox·WebKit·Node에서 같은 틱별 상태 해시와 같은 최종 기록을 내야 한다. 데모와의 동등성은 규칙·수치 단위 테스트와 통계(몬테카를로 허용 오차)로만 확인한다.

## Considered Options

- **데모와 최종 점수 일치 / 틱별 상태 일치**: 데모의 `Math.*` 호출을 그대로 옮겨야 하므로 엔진 간 결정성(M6 서버 재생 검증의 전제)과 양립하지 않는다. 데모 쪽 기준 기록을 뽑을 검증 스크립트도 저장소에 없고, 데모의 식별 입력은 렌더러 해상도에 의존한다.

## Consequences

- 데모에서 뽑은 입력 기록은 골든 기록으로 쓸 수 없다. 골든 기록은 M1 빌드에서 만든다.
- 데모와 M1의 판 결과가 달라도 그것만으로는 버그가 아니다. 규칙·수치 테스트나 통계 테스트가 깨질 때만 버그다.
