## 3. 종합 정리: 확정 가능 근거 vs 미확인 항목

### 이후 티켓에서 바로 신뢰할 수 있는 1차 사실
- **ADR 0013(무계정·무키) 필터링:** 공개 브라우저 후보는 크게 ① **whisper.cpp WASM**, ② **Transformers.js Whisper(ORT Web)**, ③ **vosk-browser(`small-ko-0.22`)**, ④ **sherpa-onnx WASM(Zipformer 스트리밍/오프라인, SenseVoice-Small, Whisper/Moonshine)**, ⑤ **Moonshine 한국어**, ⑥ **Wav2Vec2-ko ONNX / Candle WASM**으로 정리되며, **Picovoice Cheetah/Leopard Web SDK**는 AccessKey 발급 로그인과 한국어 기본 모델 부재로 조건에 부합하지 않는다.
- **라이선스 특이사항(법률 자문 없이 약관 문구만 인용):**
  - `MIT`/`Apache-2.0`만으로 구성된 조합: `vosk-browser`+`small-ko-0.22`(Apache-2.0, `NOTICE` 필수), `sherpa-onnx`+한국어 Zipformer(Apache-2.0), `whisper.cpp`+`royshilkrot` 한국어 ggml(MIT + Apache-2.0), `Transformers.js`+`Wav2Vec2-ko`(Apache-2.0), `candle`(MIT/Apache-2.0).
  - **커스텀/제한 조항 주의:** **Moonshine 한국어(Tiny/Base)**는 스트리밍 모델이 없어 MIT에서 제외된 **Moonshine Community License** 적용(상업 <$1M 등록·UI 표기·Notice 의무, 2025-09 논문 문구와 충돌). **SenseVoice-Small** 가중치는 **FunASR v1.1** 약관(출처 보존·§4.2 자동 실효·§6 자동 개정)이 적용된다.
- **브라우저 빌드 기준 '고정 교신 단어 제한' 실제 가용성:**
  - *브라우저 JS에서 그대로 동작 확인*: **Transformers.js Whisper**(소프트 토큰 `prompt_ids`/`bad_words_ids`/`LogitsProcessor`), **sherpa-onnx WASM Zipformer**(`modified_beam_search` + `hotwords`, 단 `bpe.vocab` 사전 추출 필요), **vosk-browser**(`KaldiRecognizer(sr, grammar)` API 제공, 단 `small-ko-0.22` lookahead 포함 여부 미확인).
  - *코어엔 있으나 기본 브라우저 빌드/한국어 모델에서 막힘*: **whisper.cpp WASM**(`emscripten.cpp` 미바인딩 -> 커스텀 C++ 빌드 필요), **moonshine-wasm**(`keyterms`는 스트리밍 전용 -> 비스트리밍 한국어에서 에러).
  - *지원 없음*: **sherpa-onnx 내 SenseVoice/Whisper/Moonshine**(hotwords 트랜스듀서 전용), **Transformers.js Wav2Vec2**(`argmax`), **Candle WASM Whisper**.
- **정적 호스팅 및 브라우저 호환성 제약:** `whisper.cpp WASM`과 기본 `@moonshine-ai/moonshine-wasm`은 **`COOP: same-origin` + `COEP: require-corp`(`SharedArrayBuffer`)가 필수**며(`moonshine-wasm`은 단일 스레드 재빌드 폴백 존재), `vosk-browser`·`sherpa-onnx`·`Transformers.js`·`Candle`은 **COOP/COEP 없이 단일 스레드 WASM으로 동작**한다. **WebGPU**는 Chrome 113+/Android 121+/Safari 26+에서 동작하나, **Linux에서는 Chrome 144+ Intel Gen12+ iGPU만 허용**(10세대 `i5-10210U` UHD 620 Linux 제외)되고 **Linux/Intel Mac/Android Firefox에서는 미지원**이다.
